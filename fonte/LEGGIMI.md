# Aggiornare i prezzi a mano

1. Dal telefono o dal computer (collegati dall'Italia) scarica i due file:
   - https://www.mimit.gov.it/images/exportCSV/anagrafica_impianti_attivi.csv
   - https://www.mimit.gov.it/images/exportCSV/prezzo_alle_8.csv
2. Su GitHub apri questa cartella `fonte`, tocca **Add file → Upload files**,
   carica i due file e conferma con **Commit changes**.
3. Dopo un paio di minuti il sito è aggiornato (scheda **Actions** per vedere l'avanzamento).

Il nome dei file non importa: vengono riconosciuti dal contenuto e, se ce ne sono
più versioni, si usa la più recente. Il file dei distributori cambia di rado:
basta ricaricarlo ogni tanto, i prezzi invece ogni volta.
